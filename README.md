# agent-dotfiles-template

Template para guardar num repo Git as suas preferências do **Claude Code** e do **agy (Antigravity CLI)**, sincronizadas entre máquinas.

## Como usar
1. Clique em **Use this template** → crie o **seu** repo (pode ser privado).
2. Edite `claude/CLAUDE.md` e `agy/GEMINI.md`: troque tudo entre `<...>`.
3. Siga o [TUTORIAL.md](TUTORIAL.md) para ligar os arquivos aos agentes.

## Estrutura
```
claude/CLAUDE.md   ← preferências do Claude Code
agy/GEMINI.md      ← preferências do agy
TUTORIAL.md        ← setup e dia a dia
```

Usa só o Claude Code? Pode apagar a pasta `agy/` e as seções marcadas como opcionais.
